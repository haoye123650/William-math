# Linear Equations in One Unknown · 一元一次方程

- **课程**：math-junior / S1
- **slug**：`linear-equations`
- **EDB 单元**：一次方程
- **难度**：core S1-S2，stretch S3；约30%S1 + 40%S2 + 30%S3

## 学习目标
- 解一步／两步一元一次方程（S1）
- 处理含括号与分数系数的方程（S2）
- 列方程解应用题（S2）

## Warm-up

### w1 · true-false

[S1] True or False: x = 4 is a solution of 2x − 3 = 5.

**答案：** `True`

**解析：** 2(4)−3=8−3=5，成立。

### w2 · fill-blank

[S1] Solve: x + 7 = 2.  x = ____

**答案：** `-5`

**解析：** x=2−7=−5。

### w3 · multiple-choice

[S1] Which step isolates x in 3x = 12?

- (A) Add 3 to both sides
- (B) Divide both sides by 3
- (C) Subtract 12 from both sides
- (D) Multiply both sides by 3

**答案：** `B`

**解析：** 两边同除以 3 得 x=4。

### w4 · fill-blank

[S1] Solve: 5x = −20.  x = ____

**答案：** `-4`

**解析：** x=−20÷5=−4。

## Key Ideas

**一元一次方程**：只含一个未知数，且未知数次数为 1 的方程。一般可化为 ax+b=0（a≠0）。

**等价变形**：两边同加／减同一数；两边同乘／除同一非零数；方程的解不变。

**含括号**：先去括号（注意负号分配），再合并同类项，最后把含 x 的项移到一边。

**分数系数**：可两边同乘各分母的最小公倍数去分母，再按整数方程解。

**应用题**：设未知数 → 找等量关系 → 列方程 → 求解 → 检验是否符合题意。

## Level 2

### l2-1 · fill-blank

[S2] Solve: 3(2x − 1) = 4(x + 3) − 1.  x = ____

**答案：** `7`

**解析：** 6x−3=4x+12−1 → 6x−3=4x+11 → 2x=14 → x=7。

### l2-2 · fill-blank

[S2] Solve: x/3 − x/6 = 1.  x = ____

**答案：** `6`

**解析：** 通分：(2x−x)/6=1 → x/6=1 → x=6。

### l2-3 · fill-blank

[S3] Solve: (2x + 1)/5 = (x − 1)/2.  x = ____

**答案：** `-7`

**解析：** 2(2x+1)=5(x−1) → 4x+2=5x−5 → 2+5=5x−4x → x=−7。

### l2-4 · short-text

[S2] The sum of three consecutive integers is 54. Find the middle integer.

**答案：** `18`

**解析：** 设中间数为 n： (n−1)+n+(n+1)=54 → 3n=54 → n=18。

### l2-5 · short-text

[S2] Adult ticket $a; child ticket is half. 3 adults + 4 children cost $140. Find a.

**答案：** `28`

**解析：** 3a+4(a/2)=140 → 3a+2a=140 → 5a=140 → a=28。

### l2-6 · fill-blank

[S3] For what value of k does 2x + k = 5x − 9 have solution x = 4?  k = ____

**答案：** `3`

**解析：** 代入：2(4)+k=5(4)−9 → 8+k=20−9=11 → k=3。

## Challenge (up to S3)

### c1 · short-text

[S3] Solve for x: |2x − 5| = 9. Give both solutions, smaller first, separated by a comma.

**答案：** `-2,7`

**解析：** 2x−5=9 或 2x−5=−9 → 2x=14 或 2x=−4 → x=7 或 x=−2。

### c2 · fill-blank

[S3] If (k − 1)x = 3(k − 1) has infinitely many solutions, then k = ____

**答案：** `1`

**解析：** 当 k=1 时方程化为 0=0，任意 x 都是解，故无穷多解。

### c3 · short-text

[S3] A tank is empty. Pipe A fills it in 6 h; pipe B empties it in 9 h. Both open together; after how many hours is the tank full? (Answer as a mixed number or improper fraction.)

**答案：** `18`

**解析：** 净速 1/6−1/9=1/18（箱／时），时间=18 小时。
