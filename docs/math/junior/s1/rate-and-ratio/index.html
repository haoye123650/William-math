Key Ideas

比 a : b 表示两量的相对大小，可写成分数 a/b（b≠0）。最简比：分子分母同除以最大公因数。

比例：a : b = c : d ⇔ a/b = c/d ⇔ ad = bc（交叉相乘）。

按比分配：总量按份数比例分。例：2 : 3 分 $100 → 总份 5，得 40 与 60。

速率：速度 = 路程÷时间；单价 = 总价÷数量。注意单位统一。

比例尺：图上距离 : 实际距离。常写成 1 : n。
