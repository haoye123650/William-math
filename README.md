# 尹健熙 培侨数学课程

Three DSE junior-secondary mathematics papers for a Pui Kiu student.

| Paper | Level | Difficulty | Time |
| --- | --- | --- | --- |
| Test 1 | S.1 diagnostic | ★☆☆ | 70 min |
| Test 2 | S.1 harder | ★★☆ | 75 min |
| Test 3 | S.2 | ★★★ | 80 min |

Each paper is 100 marks. Section E is extra. Calculators are not allowed.

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:43180](http://127.0.0.1:43180).

- `/paper/1` `/paper/2` `/paper/3` sit a paper
- `/print/1` blank paper
- `/answers/1` mark scheme
